Kamerabewegung um eine Szene

Die Szene besteht aus einem Würfel, einem Torus, einem Bodengitter und einer rekursiv erzeugten Kugel.

Rekursionstiefe: 3 Kugeldarstellung:

Bedienung

TasteFunktion
← / →Kamera auf einer Kreisbahn um die Szene bewegen
↑ / ↓Kamerahöhe erhöhen / verringern
N / Shift + NRadius vergrößern / verkleinern
+ / −Rekursionstiefe verändern
MausVor der Tastatursteuerung in die Szene klicken

Die Kamerasteuerung funktioniert, wenn die Zeichenfläche den Fokus hat. Die Rekursionstiefe kann auch über die Buttons verändert werden.

Umsetzung

  • Die Kameraposition lautet Eye = (r · sin(φ), h, r · cos(φ)). Der Blickpunkt ist der Ursprung, der Up-Vektor ist (0, 1, 0). Die View-Matrix wird mit einer lookAt-Funktion berechnet.
  • Die Kugel beginnt mit einem Oktaeder. Jedes Dreieck wird rekursiv in vier Dreiecke geteilt. Die Kantenmittelpunkte werden auf die Einheitskugel normalisiert. Die Dreieckszahl beträgt 8 · 4^d.
  • Der Würfel besteht aus sechs Flächen. Der Torus wird als parametrisierte Fläche mit zwei Parametern erzeugt.
